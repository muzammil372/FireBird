FIREBIRD CHICKEN — BRIGHTCODE DEMO
===================================

Files:
- index.html: page structure, SEO metadata, restaurant structured data
- style.css: responsive styling
- script.js: mobile menu, category filters, shopping cart and WhatsApp order draft

HOW TO RUN:
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, or Firefox.
3. Internet is needed for the Google Fonts and food photos (photos are remote URLs).

IMPORTANT BEFORE SHOWING TO A REAL CLIENT:
- This is a fictional demo brand, not Kababjees Fried Chicken's official website.
- Replace the brand, menu, prices, contact number, location, social links and story with the client's real details.
- In index.html replace canonical URL, Open Graph URL/image and JSON-LD telephone/address/url.
- In script.js replace both occurrences of 923000000000 with the real WhatsApp number (country code included, no + or spaces).
- Verify image licenses/usage and replace external photos with client-approved images for production.
- The current menu prices, address, phone and domain are placeholders.
- For production SEO, deploy to a real domain, add a sitemap.xml and robots.txt, connect Search Console, and ensure all page content is crawlable.
